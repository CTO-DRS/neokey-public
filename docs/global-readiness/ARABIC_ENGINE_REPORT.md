# ARABIC_ENGINE_REPORT.md — محرك العربية (W132)

## ما هو مثبت بالاختبارات الحية (اختبار، لا وصف)
- **الجذور**: 3670 جذر، عائلات عبر بحث ثنائي؛ استرداد الألفاظ المعوجة 2-دورة (RootEngineTest أخضر).
- **التشكيل**: تشكيل موثق بلا تخمين، 3 أوضاع، منتقي قراءات بالضغط الطويل (TashkeelTest أخضر) — OFF افتراضياً باحترام للمستخدم.
- **النحو**: GRX1 مع «قانون الجوانب» — كل مثال يعاد إثباته عبر المطابق الم shipped عند الحمل (GrammarNudgeTest) — OFF افتراضياً.
- **التصحيح**: Correction2 بجدول تشويش (41–69) + تصويت ثنائي سابق/لاحق + أولوية الجذر + قوانين صفر-إزعاج (حدود 8000/3000) + حماية الحقول الحساسة + قائمة never-correct (DialectCorrGate/C2Gate أخضر).
- **التعلم التكيفي**: تحلل زمني حتمي (بلا ساعة داخل المحرك — injected today) + ذاكرة 256 + روت دمج اللهجة الحية/ال seeded مع MIN_EVIDENCE=2 وإنزال MSA بعد 3 جمل بلا علامات (DialectAdaptTest/SmartSwitchTest أخضر).
- **حماية الأسماء والمصطلحات**: قائمة nocorrect + قوانين الدومين/الوظيفة في Correction2 (لا تصحيح فوق أسماء/مصطلحات المستخدم).
- **الأرقام والرموز والمختلط**: NumSmart (هندي/عربي/هجري) + المبادلات + الأرابيزي→عربي (NumSmartTest أخضر).
