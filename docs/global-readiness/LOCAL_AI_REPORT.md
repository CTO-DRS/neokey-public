# LOCAL_AI_REPORT.md — الذكاء المحلي (W132)

## القرار المعماري (بأدلة، لا ترويج)
- **المعتمد**: نواة عصبية نقية Java (NNet/NQF) — MLP next-word int8 محكم (emb64→fc240→LN→GELU→out9300)، params ≈ 2.96M، ملف 3.0MB بصيغة NQF1 ذاتية الوصف (CRC32 لكل tensor + trailer).
- **لماذا لا ONNX/TFLite الآن**: أي runtime جديد يعني اعتمادية ثنائية جديدة بلا إمكانية تحقق جهازي في هذه البيئة (BLOCKED للاختبار الحي) — مقابل نواة مقاسة فعلاً: **top3 p50=1.129ms / p95=1.217ms، صفر تخصيص في المسار الساخن** (قياس طازج 2026-11-18، PERFBASELINE_OK). المعيار هو الأداء المثبت لا شعبية الإطار — وهذا حرفياً شرط التوجيه النهائي.
- الوظائف المحلية الفعلية اليوم: توقع سياقي (Predictor gap-filler لا يزيح المعجم)، تلخيص استخلاصي، إعادة صياغة قائمة، مسودات نبرة (Assistant — صفر شبكة، مُثبت grep)، اقتراح ردود عبر شرائح العبارات.
