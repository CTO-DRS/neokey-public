## 3. درس الأسبوع — سقف dex يُدفع ثمنه بتقليم حقيقي

- أول قياس: dex **512728 > 512000** (الميزة أنفقت 7024 بايت من هامش 6296). العقيدة: تقليم لا رفع.
- التقليم (بأولوية الكود قبل السلاسل): حوار الوسوم عبر `setItems` بدل واجهة مبنية يدويًا، إسقاط
  عدّادات `Tag` غير المستخدمة (الأسماء تكفي الحوار)، مساعد `chip` مشترك، زر «تعيين» → `IME_ACTION_DONE`،
  حمولة `String` واحدة لـ `saveShortcut` → **‑604 بايت** → dex **511804** (هامش 196B).
- سلاسل المحرر الجديدة **لا تُنقل للموارد**: سطح المحرر مترجم عبر `ui_en.txt` (11 إدخالًا جديدًا أُضيفت)،
  ونقلها يكسر الترجمة الإنجليزية. جرد الرافعة المتبقية المُقاس: **~10KB** نسخ طويل غير مترجم في
  Writer/Theme/Feedback — محتوى منتج وليس نسخ واجهة؛ يُستخدم قبل أول ميزة W49+ إن لزم.
- أرضية phase4 أعيد تثبيتها بالدلتا الموثقة (نمط W47): **12984 → 6884** (dex 505704 → 511804).
