## 3. سياسة القرار (الاختبارات تحبسها)

- `OK` — شهادة رسمية → لا شيء.
- `SANDBOX` — بناء debuggable → لا شيء (تسجيل فقط). يسبق كل شيء.
- `UNKNOWN` — لا توقيعات أو فشل داخلي أو سلوك OEM غريب → لا شيء. **fail-open** عمداً:
  عطل الفحص لا يعاقب المستخدم الشرعي أبداً.
- `MISMATCH` — توقيع حقيقي غير رسمي = نمط إعادة التوقيع (جدول التهديدات: «إعادة نشر باسم
  آخر») → `Shield.allowFeature() = false` على الميزات المدفوعة **فقط**. الكيبورد وحرية
  الاستخدام المجاني لا تُمسّ. والقرار الإيرادي الحقيقي عند VIP يبقى من الخادم (طبقة 5).
