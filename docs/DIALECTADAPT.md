## 2) الصيغة

سطر لكل تطبيق، TAB فواصل: `pkg ␉ dictId ␉ updates ␉ msas`
- `dictId` ∈ {ar, ar_hijazi, ar_najdi, ar_gulf} — مطابق أسماء الأصول.
- `updates` عدد القرارات الحية المسجلة (سقف 999)، `msas` عدّاد قرارات الفصحى المتتالية.
- الأسطر الفاسدة/المجهولة/السالبة تُتخطى ولا يُرمى استثناء؛ السعة CAP=64 بالأحدث استخداماً (LRU).

## 3) القوانين

1. **لا كسر SmartSwitch**: القرار الحي بدليل ≥ `MIN_EVIDENCE` يقرر كما كان حرفياً؛ الأوضاع
   الصريحة (off/msa/fixed) لا تمر بالصنف أصلاً. البذرة لا تعبر `decide` إطلاقاً (مثبت بالبوابة).
2. **البذرة الصادقة**: الإقلاع البارد (وضع auto ونافذة فارغة) يبذّر فقط قانوناً مستقراً
   (updates ≥ ESTABLISHED=3) — غير المستقر والمنزَّل والمجهول يعيدون null (فصحى كما كان).
   لا بذرة تخمين أبداً.
3. **الإنزال المقيس للفصحى**: في تطبيق ذي قانون لهجة، ثلاثة قرارات auto-msa متتالية بلا أي
   علامة (hits=0 والنافذة ≥ 3 كلمات) تنزل القانون إلى الفصحى — اتجاه «تطبيق العمل فصحى»
   يعمل بالاتجاهين مقيساً.
4. **التعلم لكل جملة لا لكل ضغطة**: التسجيل عند إكمال الكلمة (`finishWord`) — قرار نهاية
   الكلمة بالكامل، لا كل تحديث شريط.
5. **الأوزان الموثقة (الخطوط الثلاثة)**: الكشف الحي → قاموس اللهجة يتصدر حتى cap ثم سدادة
   الفصحى (قانون C2 الأصلي)؛ البذرة (ثقة أنقض) → نصف الوزن فقط floor(cap/2) في الاقتراح
   والتنبؤ معاً؛ الخط العصبي قانونه الأصلي باقٍ (ملء الفراغات فقط، لا يزيح معجماً).
6. **التخفي (قانون 8)**: لا تسجيل جديد في التخفي أبداً (`finishWord` يعيد مبكراً)؛ الكشف
   اللحظي بلا حالة وقراءة الملف المحلي القائم تبقى كما كانت قبل W59 (لا تحليل جديد ولا
   تخزين جديد).
7. **حالة المصنع**: `reset_learn` يمحو الملف بالبايت (يحذفه) — والمسار الفارغ يحذف الملف
   عند الحفظ (لا ملف أعمى بعد المسح).

## 4) التوصيل

- البذرة تظهر فقط عبر `activeDialectId` مع العلم `dialectSeeded` الذي يمر إلى
  `mergedSuggest` و`predictions` لتنفيذ نصف الوزن.
