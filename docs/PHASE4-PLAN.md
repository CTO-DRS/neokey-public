# خطة المرحلة 4 — «من المعلقات إلى الجاهزية» (اشتقاق موثق لا افتراض)

قاعدة الاشتقاق هي قاعدة المرحلة 3 نفسها: **المرحلة القادمة تُشتق من المعلقات
الموثقة كتابةً داخل مشروع المرحلة السابقة، لا من افتراض خارجي.**

## المعلقات الموثقة التي اشتُقت منها (أين وُثقت حرفياً)

1. **التقليم الحقيقي للـ dex** — وُعد مرتين ولم يُنفذ:
   - `docs/PHASE3-W1-REPORT.md` §4.3: «وما بعده تقليم حقيقي لا رفع».
   - `docs/PHASE3-W2-REPORT.md` §4.5: «التقليم الحقيقي (لا رفع جديد) شرط بوابة
     الأسبوع 3» — وتأجّل: الأسبوع 20 لاح بالتكرار فقط (isHex64) وانتهى عند
     518,688/520,000 (هامش 1,312B لا يتسع لأسبوع ميزات واحد).
2. **الخادم الحي للمزامنة** — `docs/PHASE3-PLAN.md` (خارج النطاق) +
   `docs/PHASE3-W3-REPORT.md` §5: العقد REST موثق (`docs/SYNC-REST.md`)
   والمحاكي يثبت البروتوكول؛ الشريحة القابلة للإغلاق محلياً = خادم مرجعي HTTP
   حقيقي على الحلبة المحلية يثبت العقد على السلك لا بمكالمات صنف.
3. **مزوّد الدفع الحقيقي** — `docs/PHASE3-PLAN.md`: «topUp يستبدل لاحقاً
   باستدعاء المزوّد دون تغيير أي دالة شراء»؛ الشريحة القابلة للإغلاق محلياً =
   تحويل نقطة الاستبدال إلى عقد واجهة قياسي مثبت ببروفة مزوّد، وبقية التكامل
   (Stripe وأمثاله) تبقى قرار نشر موثقاً.
4. **نشر المتاجر** — `docs/PHASE3-PLAN.md`: خط الإصدار التدريجي آلي ومقاس حتى
   الرفع؛ الرفع نفسه يحتاج حساب متجر حقيقي (خارج البيئة) — تبقى جاهزية موثقة.

ما لا يمكن إغلاقه محلياً يبقى موثقاً لا منسياً بنصه الأصلي (مزوّد دفع حي، خادم
منشور، حسابات متاجر، أجهزة حقيقية، NNAPI، ضبط لهجات على كتابة حية، إعادة تدريب
ثقيل محجوب بالأوراكل، أرقام MAU).

## قواعد المرحلة (غير قابلة للتفاوض)

- كل أسبوع: وحدة + اختبارات إيجابية وسلبية + بوابة قاسرة + **إثبات سلبي محفوظ**
  + pipeline + تقرير + حزمة + **رفع فوري لجيثب** (commit/push/release).
- pipeline ينمو أسبوعاً (21 ← 22 ← 23 ← 24 ← 25) وينتهي بـ `PIPELINE_OK`.
- versionCode يرتفع كل أسبوع (62 → 63 → 64 → 65 → 66).
- السقف الجديد للـ dex يُثبَّت في `ci/build_r8.sh` بشرط موثق، وأي تجاوز لاحق =
  فشل بناء لا رفع سقف.
- الفئات النقية (صفر android.*) لا تُلمس بالموارد إطلاقاً — النقاء عقد معماري.
- ما تبقى خارج نطاق هذه البيئة يوثق كل أسبوع بنصه، لا يُحذف ولا يُدّعى إغلاقه.
