## 3) القوانين

1. **العداد الحتمي**: `expiryAt = capturedAt + clamp(timeout)·1000` — بايت-دقيق
   بلا ساعة داخل الكشف؛ المهلة مسار مستخدم `otp_timeout` (الافتراضي 60ث،
   الحدود 30..600، تحت الحد يرجع الافتراضي — فشل مغلق).
2. **المسح الذاتي الموثق**: `due()` — قبل المهلة لا يُمسّ شيء؛ عند/بعد المهلة
   الرمز المستحق فقط (غير الرمزي لا يُمسّ أبداً)؛ التنفيذ: حذف صف السجل
   بالمعرّف وإفراغ الحافظة بشرط تطابق النص (لا يُمسّ غيره).
3. **القانون الثنائي**: `isOtpAllowed = !incognito && prefOn` — التخفي يمنع
   الدرع كلياً حتى مع الإعداد يعمل (قراءة الحافظة تحليل — قانون 8)، والإعداد
   المغلق يمنعه بلا تخفي. وبنيوياً: الالتقاط نفسه يعود في التخفي قبل التخزين.
4. **الرموز المعلَّمة حساسة** (Android 13+) لا تُخزَّن أصلاً — أقوى من المسح.
5. **سطر التدقيق**: `OTPSHIELD␉ARMED|AUTO_WIPE␉timeout=N␉epochMs` — أوسام
   وأرقام فقط، محتوى الرمز لا يدخله أبداً.
