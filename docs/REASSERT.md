# docs/REASSERT.md — W62: أسبوع الإحكام الأ — إعادة القياس والمراجعة الأمنية

## 1) الغرض

الجزء أ من الخارطة (W54–W63) يُحكم قبل الترقية: **كل تكاليف dex تعاد القياس
على شجرة حية**، وسلبيات المحركات الخمسة تعضّ بأوسامها الدقيقة وتشفى
بايت-دقيقاً — لا ادعاء سلامة بلا هجوم حقيقي.

## 2) إعادة القياس الموثقة (نهاية W61 = نقطة W62)

- dex الطازج المُقاس مرتين (بناء R8 حي مرتين: قبل كوميت W61 وبوابة
  REASSERTGATE الطازجة): **529,224** — مطابق لـ`dex.post_trim` في الدفتر.
- المساواة المجموعية: 504192 + 4648 + 4108 − 20 + 8592 + 2412 + 3968 + 1324
  = 529,224 بالضبط.
- الهامش: 530,000 − 529,224 = **776** — فوق **خط W62 الموثق = 500** (الخط
  نفسه قرار هذا الأسبوع الموثق في NOTES، لا سقف جديد ولا رافعة).
- روافع W54 (الدفعة الثانية): تبقى **مقيسة فارغة** (قياسات W57: feedback
  −20 صافياً، والبقية مقيسة أجوفاً أو phase-locked) — لا رافعة قابلة
  للتنفيذ، فالسقف برافعاته الخمس الموثقة هو القرار السليم الوحيد.

## 3) المراجعة الأمنية — المحركات الخمسة تعضّ وتشفى

الفساد **في الذاكرة** (قلب بايت موثق — أصل الحي لا يُلمس)، والشفاء المثبت =
الأصل الحي (HEAD) يحمل ناجحاً:

| المحرك | الأصل | العضّة الموثقة |
| --- | --- | --- |
| nnet | assets/nnet_ar.nqf | NQF يرفض صارماً — «CRC mismatch» (لا نصف بناء أبداً) |
| root | assets/root_index.txt | «ROOTENGINE …» يرفض |
| tashkeel | assets/tashkeel_index.txt | «TSXENGINE …» يرفض |
| grammar | assets/grammar_rules.txt | «NUDGEENGINE GRX…» يرفض |
| dialect | المرآة vs dictsrc/dialect_markers.tsv | الانحراف يُكتشف (بناء أحمر) + الدقة الحية 100% ≥ 85% |

## 4) البوابة والإثبات

- `ci/reassert_gate.sh` + `tests/ReassertGate.java`:
  `REASSERTGATE_OK checks=16 engines=5 failclosed=ON heal=byte-exact
  acc=100.0` + قياس dex **طازج** (بناء R8 حي) →
  `REASSERTGATE_OK dex=529224/530000 margin=776 floor=500`.
- `ci/w62-negative-proof.sh` (نمط v2): ثلاث هجمات **ملفية حقيقية** على
  أصول حية (سطر مفبرك في root_index وgrammar_rules، وقلب بايت مؤكد في
  nnet_ar.nqf بXOR) → البوابة تعضّ بوسم «LIVE asset loads» الدقيق →
  الشفاء `git checkout` بايت-دقيق (git-clean يتحقق قبل الهجوم التالي).
- `REASSERTGATE_OK tests=2190/0` — الأسبوع بلا رافعة وبلا أصول جديدة
  (العدّاد الذهبي 24 باقياً)، والهوية vc 1 / 0.1.0 باقية للترقية W63.
