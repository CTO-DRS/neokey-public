> ROADMAP-V2 W55: «عقد موحد للمحركات اللغوية القادمة: مدخلات سياق موحدة،
> مخرجات معلَّمة المصدر، خروج آمن عند كل فشل — `fail-closed` كعُرف المشروع».
> هذه الوثيقة هي العقد الواحد؛ `src/Engine.java` + `src/Engines.java` هما

## 2. قوانين العقد الخمسة

1. **شكل مدخل واحد**: `Engine.Ctx{prev2, prev1, composing}` — لا يخترع محرك
   مدخله الخاص. المنشئ يسوّي أي `null` إلى `""` — لا null يدخل محركاً أبداً،
   و`toString()` يطبع الأطوال لا الكلمات (قانون الخصوصية).
2. **مخرج معلَّم المصدر**: كل مرشح `Engine.Cand{text, source}` يحمل `id()`
   المحرك — وهذا هو أساس شارات المصدر في W60 (dict/net/personal/community/…).
3. **فشل مغلق (fail-closed)** — الخروج الآمن عند كل فشل:
   - محرك يرمي أي `Throwable` → محتوى، `failures++`، والبقية تتدفق؛
   - محرك يُرجع `null` → فشل معُدّ، والبقية تتدفق؛
   - خانة `null`/فارغة في مخرج سليم → تُسقَط **وتُعَدّ**؛
   - أكثر من `MAX_PER_ENGINE = 8` مرشحاً → بترٌ للشكل (ليس فشلاً)؛
   - `Engines.run` نفسه لا يرمي ولا يُرجع null أبداً — الشريط لا يكس ولا يجوع.
4. **نقي ومتزامن**: المنطق في الذاكرة فوق الأصول (قانون 6: المعرفة في
   `assets/` والـdex مفسّر رقيق) — بلا إدخال/إخراج، بلا خيوط، بلا شبكة داخل
   `run()` (الشبكة ملك `NetGate` — قانون 10).
5. **تسجيل صارم**: `Engines.set(...)` يرفض محركاً null أو معرفاً فارغاً أو
معرفاً مكرراً **والسجل السابق باقٍ كما هو** — لا سجل نصف مبني أبداً (عُرف
`NQF.read`/`Predictor`). نداء `set()` الفارغ يفرّغ السجل (للاختبارات
والحفر). السجل وُصل W56: خيط `root-load` في الخدمة يسجل `RootEngine` عند
نجاح الختم ويتركه فارغاً fail-closed عند أي خرق (`docs/ROOT.md` §5).

## 3. نقطة الالتحام الواحدة

```java
// التسجيل (مرة واحدة عند تهيئة المحركات):
Engines.set(new RootEngine(...), new TashkeelEngine(...), ...);

// الاستهلاك (نقطة واحدة في مسار الاقتراح):
Engine.Cand[] out = Engines.run(new Engine.Ctx(prev2, prev1, composing), LIMIT);
// out: مرشحون الأفضل أولاً — ترتيب التسجيل، كل محرك الأفضل أولاً،
// مُنقّح التكرار (أول مصدر يفوز)، مغلق الفشل، بلا null أبداً.
```

الدمج حتمي ومكرر-الاختبار: الترتيب = ترتيب التسجيل، إزالة التكرار عبر المحركات
(أول مصدر يفوز)، السقف `limit` مُكرَّم، والعدّاد `Engines.failures()` دقيق
عبر البطارية كلها (لا فشل خفي). W56 وصّل أول محرك حقيقي عبر هذه النقطة
بالضبط — خيط `root-load` في `NeoKeyService` (`docs/ROOT.md` §5).

## 4. أرضية الأداء الحقيقية — `PERFBASELINE_OK`

`evidence/perf-baseline.tsv` هو السجل الواحد (نمط الدفتر، تبويبي)، مثبَّت
W55 على **الأصول الحقيقية** (القاموس 134k + نموذج `nnet_ar.nqf` الحقيقي):

| المقياس | المثبت W55 | المعنى |
|---|---|---|
| `nnet.top3.p50/p95` | 1.142ms / 1.216ms | استدلال NN — **هذا الخط الذي تقيسه W57** («صفر انحدار، p50 لا يتجاوز أرضية W55») |
| `dict.suggest.p50/p95` | 0.198 / 0.550ms | خط اقتراح القاموس |
| `dict.predict.p50/p95` | 0.001 / 0.006ms | التنبؤ بالكلمة التالية |
| `dict.load.ms` | 556ms | وكيل إنزال الخدمة (التحليل البارد) |
| `heap.mb` | 65.3MB | وكيل الذاكرة في JVM — أرضية PSS تبقى `Perf.LIMITS` على الجهاز |
| صفوف `device` (7) | مثَنا `Perf.LIMITS` حرفياً | أرضيات الجهاز الحية التي يفرضها التطبيق على نفسه |

**حارس عدم إعادة الكتابة** (الآلة التي تجعل «أرضية لا تُعاد كتابتها» قانوناً
مُفحوصاً): `PerfBaseline --check` يقرأ حرفيَّي `METRICS`/`LIMITS` من
`src/Perf.java` المُشحَّن ويرفض أي تعديل صامت — تغيير أرضية = قرار مالك
موثق في `NOTES.md` (نمط قرار السقف W54)، لا تحرير صامت أبداً.

**السجل متسق ذاتياً**: كل ميزانية jvm يجب أن تساوي `derive(value)` بالضبط
عند `%.3f` — `p50: v×1.5+1`، `p95: v×1.5+2`، `load: v×2+500`، `heap: v×2+10`.
ميزانية مفكوكة بلا قياسها المُقابل = رفض صريح. البوابة تعيد القياس طازجاً
وتفرض `measured <= budget` على كل صف.

## 5. ثمن البايتات (قانون 5)

القياس الطازج عند W55: R8 يجريد العقدَ غير المُوصَّل إلى **دلتا 0 بايت**
(dex ثابت 504,192 — لا شيء في `src` يشير إلى `Engine`/`Engines` بعد).
الصف `engine.contract` في `ci/capacity_ledger.tsv` يسجّل ذلك، وثمن البايتات
الحقيقي يُحصَّل أسبوع إيصال أول محرك حقيقي (W56) — القانون آلي عبر
`CAPACITYGATE` الذي يعيد القياس طازجاً ويعضّ على أي ادعاء قديم.

## 6. سلبيات مضغّة (المثبتة في البطارية والبوابة)

- `neg.thrower` / `neg.error` / `neg.null_output` — كل فشل يُحتوى بعدّاد
  دقيق (delta=1) والبقية تتدفق.
- `neg.holes` — الخانات الفاسدة تُسقَط وتُعَدّ (delta=2) والمخرج النظيف يتدفق.
- `set.duplicate_id` / `set.null_element` / `set.blank_id` — رفض والسجل
  السابق باقٍ.
- `failures.counter.exact` — العدّاد يساوي مجموع المتوقع عبر البطارية كلها.
