## 2) قانون الترتيب السياقي الكلي (الشريط الواحد)

الشريط يُبنى عبر **التحام واحد لكل تمرير** (`Engines.run` / `engineRun`) والترتيب
الموثق حتمي:

1. **المعجم يتصدر**: إكمالات الكلمة الجارية (المعجم المدمج بحسب اللهجة —
   الكشف الحي يتصدر حتى cap والبذرة بنصف الوزن، قانون W59).
2. **المقعد الشخصي**: أعلى نقش فعّال (التوهين الزمني، قانون W60) — قبل العصبي
   في التنبؤ، append-only في الشريط، بشارة ★ مرئية.
3. **السدادة العصبية**: تملأ الفراغات فقط ولا تزيح معجماً أبداً (قانون A2).
4. **الجذر ذيل الشريط** (شجرة العائلة بالضغط الطويل — W56)، والتشكيل والنحّاخ
   يلحقان بمساحة متاحة (W56/W58).
5. كل المحركات عبر العقد الواحد — لا استدعاءات متفرقة، والتخفي يخضعها كلها
   **مرة واحدة** (`engineRun` تعيد فارغاً — الركوبات no-op بنيوياً).
