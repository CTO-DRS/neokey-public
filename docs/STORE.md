# عقد متجر السمات — صيغة الحزم .neokey وخط المراجعة والاقتصاد

المرحلة 2، البند B («متجر السمات وبرنامج المبدعين»). هذا العقد هو ما تفرضه
المنصة قبل نشر أي حزمة — العميل (`Theme.importPack`) يبقى متسامحاً بحكم تصميمه،
أما **المتجر فهو الجانب الصارم**: الحزمة إما تمر بكل قواعد هذه الوثيقة أو لا
تصل لأي مستخدم.

## 1. صيغة الحزمة (pack format v1)

الحزمة JSON واحد بالشكل نفسه الذي تنتجه `Theme.exportPack` — قيم الألوان نصوص
hex (`#RGB` / `#RRGGBB` / `#AARRGGBB`)، والحقول:

- إلزامية: `neokey=1`، `name`، `bg`، `key`، `vendor`
- ألوان اختيارية: `bg2, keyPressed, special, text, specialText, shadow, enter,
  enterText, icon, hint, popup, popupText, space, border, glow, glow2`
- أرقام/قيم: `borderW` (0.5..8)، `font` (0..5)، `anim` (-1..29)،
  `glass`، `photo`، `neon` (+`glow`/`glow2` إلزامية معه)، `app` (يجب `"NeoKey"`)
- `layout` (إعدادات تُطبَّق مع السمة): `keyshape` 0..5، `radius` 0..40،
  `keygap` 0..12، `hpct` 60..220، `wpct` 60..200، `keysize` 0..2،
  `pressglow` (boolean) — **لا مفاتيح أخرى داخلها**
- `vendor`: معرّف المبدع — يجب أن يكون في سجل المؤسسين وقت المراجعة

**لا شيء آخر.** أي مفتاح أعلى غير القائمة يرفض الحزمة فوراً (`key:<name>`) —
هذا هو حاجز «المفاتيح المزروعة»: حزمة تحمل `api_key` أو `webhook_url` أو أي
حقل تتبّع لا تُنشر أبداً، حتى لو كانت ألوانها سليمة.

## 2. قواعد المراجعة الآلية (`ThemePack.review`)

| الفئة | القاعدة | وسوم الرفض |
|---|---|---|
| الحجم | ≤ 64 KB (السمة بيانات وصفية؛ الأكبر تهريب) | `size` |
| JSON | محلل صارم: لا مفاتيح مكررة، لا محارف تحكم خام، لا لاحقة زائدة، عمق ≤ 8 | `json:dup/ctrl/trailing/depth/...` |
| الهوية | `neokey=1`، `app="NeoKey"` عند الوجود، الكائن فقط | `version`, `app`, `shape` |
| المورّد | معرّف معلن + مسجَّل في المؤسسين | `vendor.missing`, `vendor.unknown` |
| النص العربي | الاسم 1..40 محرفاً، بلا محارف اتجاه (U+202A..202E, U+2066..2069, U+200E/200F)، بلا تطويل (U+0640)، بلا تشكيل، بلا فراغ طرفي | `name.bidi/tatweel/tashkeel/length/ws` |
| الألوان | hex صالح؛ شفافية `bg` ≥ 0x40 | `color:*`, `color.bg.alpha` |
| النطاقات | كما في §1 — المتجر يرفض ما يتسامح معه العميل | `range.*`, `layout.*` |
| التباين | WCAG 2.1 (نسبة الإضاءة) ≥ 3.0 لزوجي `key/text` و`enter/enterText` و`special/specialText`، مع دمج الشفافية فوق الخلفية | `contrast.*` |
| هوية النيون | `neon=true` ⇒ `glow` + `glow2` | `neon.glow` |

التباين يقاس على اللون **المركّب** (المفتاح الشفاف مدموج فوق `bg`) — القاعدة
المقاسة، لا المظهرية.

## 3. النشر مثبَّت بالتجزئة (hash-pinned publish)

النشر لا يقبل إلا **البايتات نفسها** التي مرّت المراجعة: `sha256` للحزمة يُسجَّل
في الكتالوج وقت القبول، وعند النشر يُعاد الحساب — أي انحراف بايت واحد بعد
المراجعة يرفض الحزمة. هذا يسد هجوم «العبث بعد القبول» حتى لو كانت النسخة
المعدَّلة ستمر بالمراجعة نفسها.

## 4. الاقتصاد 70/30 (`Economy`)

- الحساب بالسنتات الصحيحة فقط — لا فاصلة عائمة قرب المال أبداً.
- التقسيم: المبدع `floor(سعر × 70 / 100)` والمنصة **الباقي** — فالمجموع
  يساوي السعر دوماً بلا سنت ضائع (سعر 1 سنت → 0/1).
- `monthClose`: تجميع بالبائع، الاسترداد يُسقط سنتاً بسنت، واسترداد يفوق
  إجمالي بائعٍ ما لا يجعل رصيده سالباً — المنصة تمتصه وتُبلغ عنه (`adjustments`)
  ولا يلمس باقي المبدعين.
- حد الدفع الأدنى 10.00$ (`MIN_PAYOUT_CENTS=1000`) على **نصيب المبدع**؛ ما
  دونه يُحمل للشهر التالي، وما فوقه يُدفع كاملاً. الدفعة idempotent —
  الاستدعاء الثاني يدفع صفراً بالضبط.
- كشوف الشهور مرتبة بمعرّف المبدع — حتمية: المدخل نفسه = الدفتر نفسه على أي
  جهاز.

## 5. كتالوج المؤسسين

`dictsrc/founders_catalog.json` (schema `neokey-founders-1`، مولَّد بـ
`dictsrc/make_founders.py`، seed 20261103): 10 مبدعين مؤسسين × 25 حزمة حصرية
بهوية الزجاج/النيون، كل حزمة بنص JSON كانوني (مفاتيح مرتبة، بلا فراغات) +
`sha256` لبايتاتها + سعرها بالسنتات. المولّد يُثبت أزواج التباين رياضياً بنفس
حسابات `ThemePack` قبل كتابة الملف، والبوابة تعيد إثباتها في Java —
مصدرا الحقيقة متطابقان بلا اتفاق مصادفة.

## 6. البوابة

`ci/theme_store_gate.sh` → `ThemeStoreGate` (نقي JVM): مراجعة الكتالوج كاملاً
+ دبوس التجزئة + 23 حزمة ضارة مصممة تُرفض كلها بالوسم الصحيح + عبث ما بعد
المراجعة + شهر كامل محاكى على الكتالوج (انغلاق الدفتر 70.00/30.00 بالضبط)
+ زمن المراجعة p50 (الحد < 5ms). المرحلة 15 من `pipeline.sh`، وأرقامها في
`gates.env` تحت `THEMESTORE_*`.
