# تقرير الأسبوع 6 — إغلاق البند A (الجزء الكودي): لوحة الاستقرار والتقرير المجهول

**التاريخ:** 2026-11-02 · **المرجع:** خارطة الطريق، المرحلة 0، البند A + معيار الخروج · **versionCode:** بلا تغيير (56/1.0)

## 1. موقع هذه الخطوة

بعد إغلاق البند C كاملاً (الأسبوعان 4–5: R8 + درع التحقق الزمني)، يبقى البند A «الاستقرار
والجودة القابلة للإثبات» على ثلاث قطع كودية لم تُنجز: «لوحة استقرار في مركز الأداء»
(مكتملة الوظيفة الأمنية لا العرض)، «ربط سجل الأعطال بخدمة تقارير مجهولة الهوية بالكامل»،
و«قياس أداء أساسي مسجل: P50/P95 لفتح اللوحة والضغط والتبديل». هذا الأسبوع أغلق الثلاثة
من الطرف الكودي.

## 2. ما بُني

| المكون | الوصف |
|---|---|
| `CrashReport.java` | منطق نقي: تقرير استقرار مجهول (`neokey-crash-1`) + خط أساس مرجعي (`neokey-baseline-1`) + تطهير مواقع الأعطال (النمط الوحيد المقبول `Class.method:line`، حد 80 حرفاً، أي مسار/رابط/نص → `unknown`) |
| لوحة الاستقرار (PerfActivity) | قسم «الثبات» أصبح لوحة: جلسات/أعطال/معدل + **عمر آخر عطل بالأيام** + **حالة الدرع** + ثلاثة أزرار: تقرير الأعطال المجهول، خط الأساس المرجعي (P50/P95)، تصفير عداد الأعطال (بتأكيد) |
| إصلاح خصوصية موجود | `Perf.report()` كان يصدّر صانع الجهاز وموديله — يناقض العقد المعلن «أرقام فقط»؛ أُزيل واستُبدل بـ `version_code` |
| ترجمات | 13 زوجاً فريداً في `assets/ui_en.txt` |

## 3. عقد الخصوصية (28 اختباراً تحبسه)

التقرير: `schema, report_version, app, version_name, version_code, android_api, sessions,
crashes, crash_rate_pct, last_crash{type, where, days_ago}, shield, metrics{p50_ms, p95_ms},
generated_at`. **لا معرفات جهاز إطلاقاً** (اختبار regex يفشل البناء عند أي تسرب)، العطل
بالأيام لا بالأوقات الدقيقة، ولا إرسال من الكود — لا نقطة نهاية موجودة أصلاً؛ الخروج
يدوي (مشاركة/نسخ) والخدمة السحابية تُفعَّل لاحقاً بموافقة صريحة عند وجود خادم.

## 5. بقايا البند A — تحتاج أجهزة/خوادم (موثقة، ليست نسياناً)

1. اختبارات واجهة على محاكيات أندرويد الخمسة (لا محاكيات في بيئة التطوير).
2. الخدمة السحابية للتقارير + toggle موافقة صريحة (لا خادم؛ العقد جاهز في STABILITY.md §2).
3. تشغيل «خط الأساس المرجعي» فعلياً على الجهازين المرجعيين وتسجيل الناتج مع الإصدار.
4. آخر عطل معلّق: بانتظار تقرير `last_crash.txt` حقيقي (آلية الرمزية عبر mapping جاهزة).
