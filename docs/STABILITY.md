# لوحة الاستقرار + تقرير الأعطال المجهول (المرحلة 0، إغلاق البند A — الجزء الكودي)

> المرجع: البند A — «ربط سجل الأعطال بخدمة تقارير مجهولة الهوية بالكامل تحترم مبدأ
> الخصوصية» + المخرجات: «لوحة استقرار في مركز الأداء» + معيار الخروج: «قياس أداء أساسي
> مسجل: P50 وP95 لفتح اللوحة والضغط والتبديل بين اللغات».

## 1. ما كان موجوداً وما أضيف هذا الأسبوع

**الموجود سابقاً** (الإصدارات 17–20): مركز الأداء بقسم «الثبات» (جلسات، عدد الانهيارات،
معدل الانهيار، آخر عطل)، مقاييس حية بـ p50/p95 لسبعة مقاييس، معالج أعطال يكتب
`last_crash.txt` + عداداً محلياً، واختبار بطارية ودقة.

**المضاف** (الأسبوع 6):

| المكون | الوصف |
|---|---|
| `CrashReport.java` | منطق نقي (صفر `android.*`): تقرير استقرار مجهول بعقد منشور + خط الأساس المرجعي + تطهير مواقع الأعطال |
| لوحة الاستقرار الموسعة | قسم «الثبات» أصبح: + «عمر آخر عطل» (أيام)، + «حالة الدرع» (من درع الأسبوع 5)، + 3 أزرار: تقرير الأعطال المجهول · خط الأساس المرجعي (P50/P95) · تصفير عداد الأعطال (بتأكيد) |
| عقد الخصوصية الموسع | `Perf.report()` كان يصدّر صانع الجهاز وموديله — **أزيل** (معرف جهاز يناقض «أرقام فقط» المعلنة) واستُبدل بـ `version_code` |

## 2. عقد التقرير المجهول (منشور ومُختبر — 28 اختباراً)

الحقول حصراً: `schema, report_version, app, version_name, version_code, android_api,
sessions, crashes, crash_rate_pct, last_crash{type, where, days_ago}, shield,
metrics{key:{p50_ms,p95_ms}}, generated_at`.

- **أرقام فقط + إطار عطلنا**: موقع العطل يمر عبر `sanitizeWhere` — النمط المقبول الوحيد
  `Class.method:line` (بما فيه أصناف داخلية `$`)؛ أي مسار أو رابط أو نص خارجي → `unknown`
  (والحد 80 حرفاً).
- **لا معرفات إطلاقاً**: اختبار regex يفشل البناء عند ظهور imei/serial/android_id/model/
  fingerprint/mac/مسار/رابط في التقرير أو خط الأساس.
- **الخصوصية الزمنية**: العطل يُصدَّر «بالأيام» فقط (`days_ago`) — لا أوقات دقيقة.
- **لا إرسال من الكود**: لا نقطة نهاية في هذا الإصدار أصلاً؛ التقرير يخرج يدوياً (مشاركة/
  نسخ) والخدمة السحابية تُفعَّل لاحقاً بموافقة صريحة (toggle) عند وجود خادم. هذا هو
  «بالكامل تحترم الخصوصية» من الطرف الذي نملكه الآن.

## 3. خط الأساس المرجعي (معيار الخروج)

زر «خط الأساس المرجعي (P50/P95)» يولّد `neokey-baseline-1` JSON بمقاييس
`create/show/key/frame/sugg/ai` (فتح اللوحة، الظهور، الضغط، الإطار، الاقتراحات، الذكاء)
بقيم `p50_ms/p95_ms` للإصدار الحالي — تُحفظ بجانب كل إصدار عند توفر الجهاز المرجعي
(النصف الذي يحتاج جهازاً حقيقياً موثق أدناه).

## 4. ما اكتشفه R8 على هذا الكود

- `CrashReport` **أدرج inline بالكامل** في مواضع استدعائه (لا سطر صنف في mapping لكن
  دواله ظاهرة مدمجة، والسلاسل `"neokey-crash-1"` حية في dex) — التحسين الأقصى.
- `Integrity → a.D0` · `Shield → a.Y1` · `Perf → a.f1` — تشويش كامل، `PerfActivity`
  باسمها (قاعدة keep للمانيفست). حجم dex: 429,892 بايت (+4,476 عن الأسبوع 5 — وزن
  اللوحة والتقرير كاملين).
